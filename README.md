# Address Book Management System in C

## 📌 Project Overview

The Address Book Management System is a menu-driven application developed in **C programming** to manage contact information efficiently.

The application allows users to add, search, edit, delete, and list contact details. Contact information is stored using **file handling**, allowing the data to be preserved even after the program is closed.

---

## 🎯 Objective

The main objective of this project is to develop a simple and efficient contact management system using core concepts of C programming such as:

* Structures
* Arrays
* Functions
* Pointers
* File Handling
* String Manipulation
* Searching
* Data Validation
* Modular Programming

---

## ✨ Features

### 1. Add Contact

Allows the user to add a new contact with details such as:

* Name
* Mobile Number
* Email Address

### 2. Search Contact

Allows the user to search for a contact using available contact information.

### 3. Edit Contact

Allows the user to modify the details of an existing contact.

### 4. Delete Contact

Allows the user to remove a contact from the address book.

### 5. List Contacts

Displays all available contacts stored in the address book.

### 6. Save Contacts

Contact information is stored in a CSV file so that the data can be accessed later.
